## ¿Qué es Git?
Es un sistema de control de versiones distribuido que permite registrar cada modificacion realizada 
en un codigo fuente, que nos facilita la colaboracion masiva sin riesgo de perder informacion o revolverla con la de otros 
colaboradores, teniendo cada una su version modificada y la version original para trabajar en equipo.

## Por qué necesitamos Git
Git es necesario para un ambiente de trabajo en equipo, organizado y limpio, permitiendo guardar cambios y 
tener un historial de ello, ya sea en repositorios, carpetas, etc.Permitiendo tambien la creacion de ramas para hacer 
trabajos sin interrumpir a los demas. 

## Los 3 conceptos clave de Git

1. **Repositorio:** Es la carpeta que almacena un proyecto, archivos, imagenes. Puede existir de manera remota 
y de manera local.
2. **Commit:** Es basicamente el boton de "guardar" de Git, ya que guarda un registro permanente de tus cambios
en la linea del tiempo del proyecto. Es como crear un punto de control, siendo que si algo sale mal puedes regresar 
exactamente a ese momento.
3. **Rama:** Es una linea de tiempo que permite desarrollar nuevas funcione o corregir errores sin alterar 
el codigo principal que ya funciona. Es la herrramienta clave para que varios programadores trabajen en distintas partes
de un mismo proycto sin simultaneamente sin estorbarse.

## Los comandos que aprendí
git clone: Descarga una copia exacta de un repositorio.
git push: Sube los commits a GitHub.
git pull: Descarga y fusiona los ultimos cambios de los archivos.
git init: Crea un repositorio en la carpeta actual.
git commit -m "Mensaje": Guarda los cambios con texto que describe que se hizo.
git status: Muestra que cambios se hicieron en archivos y que falta modificar.
git add: Prepara cambios realizadospara luego ser subidos.
git log --oneline: Muestra la lista de cambios en una sola lista para cada commit.
